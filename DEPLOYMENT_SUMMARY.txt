🚀 DEPLOYMENT STEPS
───────────────────────────────────────────────────────────────────────────────

1. BACKUP DATABASE
   $ pg_dump -h your-host -U postgres vetmax > backup-$(date +%s).sql

2. APPLY MIGRATIONS
   $ psql -h your-host -U postgres vetmax < supabase/migrations/0046_core_management_tables.sql
   $ psql -h your-host -U postgres vetmax < supabase/migrations/0047_grooming_cashier_integration.sql

3. VERIFY RPC FUNCTIONS
   $ psql -h your-host -U postgres vetmax << EOF
   SELECT routine_name FROM information_schema.routines
   WHERE routine_name LIKE 'rpc_%' ORDER BY routine_name;
   EOF

4. SET ENVIRONMENT VARIABLES
   $ export SYSMAX_MASTER_KEY="your-secret-key-here"
   $ export MODULE_GOVERNANCE_STRICT="false"  # or "true"

5. DEPLOY NEXT.JS APP
   $ npm run build
   $ npm start

6. SMOKE TEST
   - Create product price
   - Create cashier entry
   - Finish grooming session (check cashier entry created)
   - Validate scheduling slot
   - Enable module with master key
